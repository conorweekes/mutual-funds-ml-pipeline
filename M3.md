## 1. AI model selection

I compared two regression models using the development set rather than the final test set.

| Model | Reason for trying it |
| --- | --- |
| `DummyRegressor` | Predicts the mean training return for every fund. It provides a simple baseline. |
| PyTorch neural network | Can learn relationships that are more complex than a simple linear model. Its size can be adjusted and training is practical with the available data. |

**Initial development results from Notebook 1:**

| Model | MAE (percentage points) | RMSE (percentage points) | R² | Training time |
| --- | ---: | ---: | ---: | ---: |
| Dummy baseline | 4.379 | 5.876 | −0.0003 | 0.001 s |
| PyTorch neural network | **2.545** | **3.814** | **0.5785** | **4.915 s** |

For the first PyTorch experiment I used two hidden layers of 16 neurons each, ReLU activations, the Adam optimizer, a learning rate of `0.003`, a batch size of `256`, and `20` epochs. The neural network gave the lowest MAE of the two initial models, so I chose it for more systematic optimisation in Notebook 2.

The PyTorch learning curve also showed training and development MSE generally decreasing during the 20 epochs. There was no clear sustained increase in development loss while training loss fell. 


## 2. Hyperparameter optimization

I performed a grid search using the approach from Lab 8. A grid search tests every combination of specified hyperparameter values.

| Hyperparameter | Values tested |
| --- | --- |
| Hidden size (neurons in each hidden layer) | `8`, `16`, `32` |
| Learning rate | `0.001`, `0.003`, `0.01` |

For this grid search, I used three hidden layers with Sigmoid activations, following the neural network structure demonstrated in Lab 8. I removed the final Sigmoid because my model predicts numerical returns.

I used the Adam optimizer, MSE loss, 15 epochs, batch size 256 and random seed 42.

This produced nine PyTorch configurations and one DummyRegressor baseline, giving 10 results in total.

I used the development MAE to select the best configuration. RMSE and R² were also recorded. The test set was not used for hyperparameter selection.

**Notebook 2 results, ordered by development MAE:**

| Model | Hidden size | Learning rate | MAE (pp) | RMSE (pp) | R² |
| --- | ---: | ---: | ---: | ---: | ---: |
| PyTorch | **16** | **0.01** | **2.760** | **4.008** | **0.5345** |
| PyTorch | 32 | 0.01 | 2.867 | 4.101 | 0.5127 |
| PyTorch | 32 | 0.003 | 2.939 | 4.226 | 0.4826 |
| PyTorch | 8 | 0.01 | 2.943 | 4.175 | 0.4951 |
| PyTorch | 16 | 0.003 | 3.001 | 4.250 | 0.4767 |
| PyTorch | 8 | 0.003 | 3.002 | 4.336 | 0.4553 |
| PyTorch | 8 | 0.001 | 3.116 | 4.525 | 0.4068 |
| PyTorch | 32 | 0.001 | 3.184 | 4.580 | 0.3922 |
| PyTorch | 16 | 0.001 | 3.362 | 4.673 | 0.3674 |
| Dummy | — | — | 4.379 | 5.876 | −0.0003 |

The best configuration within the Notebook 2 grid search used 16 neurons per hidden layer and a learning rate of 0.01. It achieved development MAE of 2.760 percentage points and R² of 0.5345.

The results show that the learning rate of 0.01 performed best for all three hidden sizes tested, although the largest network did not produce the lowest MAE.

Notebook 1 achieved a lower development MAE of 2.545 percentage points using two hidden layers and ReLU activations. Notebook 2 used a different architecture with three hidden layers and Sigmoid activations.

Therefore, the grid search did not improve upon the initial model. I continued with the best Sigmoid model for the final evaluation because it was selected and saved through the Lab 8 grid search and MLflow process, rather than because it had the lowest MAE overall.

## 4. Analysis and conclusions from experiments

The DummyRegressor baseline produced a development MAE of 4.379 percentage points, while the selected PyTorch model achieved 2.760 percentage points. This represents an MAE reduction of approximately 37% compared with the baseline.

The grid search identified the best model among the nine Sigmoid configurations. However, Notebook 1's initial ReLU neural network achieved a lower development MAE of 2.545 percentage points.

After selecting the model using the development set, I evaluated the saved model on the separate test set containing 2,256 funds.

| Metric | Development | Final test |
| --- | ---: | ---: |
| MAE | **2.760 pp** | **2.790 pp** |
| RMSE | **4.008 pp** | **4.292 pp** |
| R² | **0.5345** | **0.4957** |

The test MAE was slightly higher than the development MAE. The increase in RMSE suggests that some larger prediction errors may have occurred on the test set.

The model was tested on unseen funds, but its ability to predict returns in future periods remains untested.

## 5. Compute architecture selection 

I used the CPU runtime in Google Colab rather than a GPU or distributed training. The dataset contained 18,107 training records and three input features. The selected neural network was relatively small and the winning experiment recorded a training duration of approximately 5.67 seconds. Therefore, I considered a CPU sufficient for this project.

## 7. Model card

**Model name:** Mutual Funds Q1 2021 Return Regressor

**Model type:** PyTorch neural network (MLP)

**Purpose:** Predict a mutual fund's Q1 2021 return using its returns from 2017, 2018 and 2019.

**Architecture:** Three input features, three hidden layers containing 16 neurons each, Sigmoid activations and one numerical output without a final Sigmoid.

**Training:** Adam optimizer, learning rate 0.01, batch size 256, MSE loss and 15 epochs.

**Training data:** 18,107 records, with separate development and test datasets.

**Evaluation:** Final test MAE of 2.790 percentage points, RMSE of 4.292 percentage points and R² of 0.4957.

**Limitations:** The model uses only three historical return features and struggles with some unusually high or low returns. Its performance on later periods has not been evaluated. The initial ReLU model also achieved a lower development MAE.

**Intended use:** Educational purposes.

## 8. Error analysis and model weaknesses

In Notebook 3, I compared the predicted fund returns with the actual returns in the development dataset. The overall MAE was 2.760 percentage points.

I created a scatter plot comparing actual and predicted returns and displayed the 10 funds with the largest absolute errors.

The graph showed a general positive relationship between actual and predicted returns although the model tended to predict less extreme values than some actual returns.

For example, fund AMREX had an actual return of 42.520%, while the model predicted approximately 10.988%. This produced an absolute error of 31.532 percentage points.

The model also struggled with some unusually negative returns. These errors suggest that three historical return features may not capture enough information to predict very high fund performance.

The error analysis demonstrates a limitation of the model, particularly when predicting unusually high or low returns.
